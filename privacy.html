4. Как данные обрабатываются

Данные из формы передаются по защищённому соединению (HTTPS) через сервис Cloudflare в личный чат оператора в мессенджере Telegram. Сервис Cloudflare только пересылает заявку и не сохраняет её содержимое. Оператор вручную читает заявку, связывается с вами и при необходимости записывает в свои рабочие заметки то, о чём вы договорились.

Выполняются действия: сбор, запись, хранение, использование, передача (в Telegram, как описано ниже), удаление. Решений, порождающих юридические последствия для вас, на основании только автоматической обработки не принимается.
